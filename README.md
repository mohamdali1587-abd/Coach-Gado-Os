# Coach Gado Fitness Hub

Arabic RTL fitness coaching workspace for Coach Gado.

## Stack
- Static PWA frontend hosted on Vercel
- Supabase Auth + Postgres Data API
- Row Level Security on client-facing tables
- Supabase project: `glvkkbqtgwfezurkbmek` (Europe Central)

## Account setup
1. Open the deployed app and create an account using your email.
2. Coach account: choose **Coach** and enter the one-time coach activation code supplied privately by the owner.
3. Client account: choose **Client** and use the invite code generated by the coach for the invited email.
4. Confirm email if Supabase Auth requests it, then sign in.

## Data security
The browser uses only the Supabase publishable key. Never add a service-role or secret key to frontend files. RLS policies enforce coach/client boundaries. Billing tables are coach-only.

## Offline
The PWA caches the app shell. Data operations require an internet connection; offline write-queue sync is not yet implemented.

## Deployment
Vercel project: `coach-gado-fitness-hub-app`. Deploy from `main` after review.


## Automated coaching (initial release)
- Client assessment intake: age, sex, height, current weight, goal, activity, experience, training frequency, equipment, limitations, food preferences, and allergies.
- Rule-based training program suggestions from the existing exercise library.
- Nutrition target estimation using Mifflin-St Jeor and the client's goal/activity profile, with meals assembled from the existing food library.
- Check-in summaries and coach-facing progression suggestions from recorded workout sets.
- Generated plans are drafts: the coach must review exercise selection, food allergies/preferences, portions, and targets before assigning them.
- Offline write queue and background synchronization are not implemented yet.
